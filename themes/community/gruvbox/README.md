# Gruvbox

Retro groove color scheme — a warm, medium-contrast dark theme that's easy on the eyes over long sessions. Ported to Panther from the classic [morhetz/gruvbox](https://github.com/morhetz/gruvbox).

## Palette
- Background `#282828` · panels `#3c3836`
- Foreground `#ebdbb2`
- Primary `#fabd2f` (gruvbox yellow)
- Gains `#b8bb26` / Losses `#fb4934`
- Accents — orange `#fe8019`, blue `#83a598`, purple `#d3869b`, aqua `#8ec07c`
